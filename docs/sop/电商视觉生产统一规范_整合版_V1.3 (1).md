## 2. 规则分层与冲突处理

所有规则必须标注属于：真实产品事实、已核实现行平台规则、内部生产标准、项目专项约定、待核实项，不能混写。

执行约束顺序：真实外观/参数/SKU → 真实使用与支撑关系 → 当前视角及可见面 → 准确卖点与文案 → 版式、背景、光效。平台发布要求另行核验；若与实物表达冲突，调整角度、版式或发布方案，不篡改实物。

参考依据优先采用用户最新明确确认的实物照片、用户指定白底图、局部实拍、已确认锁定档案、经验证规格。AI推导与行业常见结构不能作为确认依据。两项事实相互矛盾时记录具体冲突，暂停受影响内容，继续其余有依据部分。

## 3. 任务入口与输入要求

先区分：资料整理、策划、仅提示词、实际出图、改图、质检。仅提示词不生成图片；实际出图不能用策划冒充完成；提示词通过不代表成图已通过视觉验收。

任务单记录：型号、颜色、接口/套装SKU、平台、国家、语言、发布位置及类目、图数、比例、导出要求、原始参考、规格版本、包装清单、配件视觉参考、尺寸证据、品牌授权、禁用面、专属约定、当前档案版本。

缺项一次集中列明，继续完成有依据部分。不以同类产品参数、历史型号或最高配补空缺；不重复索要当前已可访问资料。

参考编号R01起，分别标为产品结构、配件、包装、风格、使用场景。每张正式提示词列明实际附件顺序、文件名及职责；编号不代表执行模型自动访问了图片。风格图只借视觉语言，不能借其产品结构、接口、Logo或配件。

## 4. 产品复写与空间锁定

产品复写不得演变为产品再设计。允许改变环境、构图与合理光线，必须保持真实结构。

### 4.1 参照面先于各面识别

1. 选择唯一参照面，优先正面；正面不明确时选择结构最完整、方向最明确的面并说明依据。
2. 以观察者正对参照面的方向统一左右，不能根据照片画面左右临时改名。
3. 明确正常使用姿态，建立FRONT、BACK、LEFT、RIGHT、TOP、BOTTOM映射；非正面参照时额外写明参照面与这些物理面名称的对应，避免把顶部参考误叫正面。
4. 记录各面相对、相邻、连接边界及朝向，验证前后相对、左右不镜像、上下不混淆。
5. 将接口、按键、标签、凹槽等绑定到唯一物理面，再进入细节锁定。

异形产品按真实形体记录，不强套六块长方形。未提供的面只是未知，不能据此认定它没有结构。

状态：CONFIRMED=有依据确认；NOT PROVIDED=未提供；UNVERIFIED=不能验证；CONFLICT=资料冲突；LOCKED=完成相应确认并冻结。LOCKED只覆盖已确认范围。

### 4.2 必锁内容

| 对象 | 必须记录 |
|---|---|
| 整体几何 | 轮廓、长宽高比例、厚度、圆角倒角、上下壳、弧面、接缝与连接方式 |
| 接口与控件 | 名称、数量、所属面、指定观察方向下的顺序、朝向、形状、边距及周边结构 |
| 材质与颜色 | 材料身份、哑光/高光等工艺、纹理方向、透明度、固有色与反射特征；无证据不推定具体材料 |
| 标识与贴图 | 品牌、型号、按键文字、装饰图案的内容、位置、比例、方向、所属面 |
| 配件 | 每件独立建卡：外形、尺寸关系、材质颜色、数量、两端接头、插头标准及印字 |
| 遥控器 | 外壳、完整键数、布局、键形、键色、印字及快捷键，不用近似款替代 |

禁止增加/删除/迁移接口、把两面的接口合成一面、补造底面脚垫螺丝、镜像、拉伸、改材质、擦改原生Logo。配件不得跨型号混用。

### 4.3 允许变化与复写路线

优先原图抠图、精修、等比缩放和分层合成。保留真实孔洞、边缘、纹理和印字；可清理灰尘白边、修正曝光与自然光影。平面旋转不能替代真实换面；透视变换不能制造未提供的侧面。

AI重绘或3D复写只使用有证据的结构与角度，逐项验证。模型无法稳定保留接口、按键、线头或文字时，改用真实素材合成/局部修复。不得用强光、裁切、手部或标题掩盖结构错误。

## 5. 产品拍摄角度、摄像机机位与镜头规范

本章适用于实拍、3D渲染、AI图像提示词与后期合成。属于内部摄影与视觉执行规范；焦段和光圈范围是起始方案，不是平台要求或保证画面准确的参数。新增摄影知识与执行建议不能反推为已经测得的历史照片拍摄数据。

### 5.1 必须区分的摄影变量

| 变量 | 定义 | 不能混淆的内容 |
|---|---|---|
| 产品朝向与姿态 | 产品在场景中如何转向、平放、竖立或倾斜 | 产品转动与相机绕拍须分别记录 |
| 相机水平机位 | 相机位于产品哪一侧、绕产品多少角度 | 不是产品在画面内旋转的角度 |
| 相机高度与仰角 | 相机相对产品基准点的高度和位置仰角 | 高机位不等于一定大幅俯拍；还取决于瞄准点 |
| 相机俯仰/瞄准 | 镜头光轴向上或向下，以及瞄准哪个位置 | 不把机位仰角与光轴俯仰写成同一个量 |
| 相机滚转 | 相机绕光轴旋转形成画面倾斜 | 不会凭空改变可见物理面 |
| 焦段与画幅 | 焦距配合传感器尺寸决定视场范围 | 不能只写85mm而省略实际/等效含义 |
| 机距 | 相机视点与产品基准点的距离 | 不等于镜头前端到产品的工作距离 |
| 景别与主体占比 | 全景、近景、特写及画面中产品大小 | 特写不等于使用微距镜头 |
| 光圈、对焦、景深 | 焦点落点与可接受清晰范围 | 背景虚化不代表主机可以失焦 |

镜头焦段以“全画幅等效视角”沟通；实际拍摄另记录传感器画幅、实际焦距与光圈。等效焦距只用于比较视场，不把它当作景深或曝光完全等效的依据。微距表示近摄能力与放大率，不是一种固定焦距，也不是成品画幅1:1。

### 5.2 统一方向与角度命名

沿用第4章参照面与物理面定义。LEFT/RIGHT均指项目已锁定的物理侧面，不再按画面左右临时命名。

- 水平方位θ：相机位于FRONT正前方为0°；向已定义RIGHT移动为正，RIGHT为+90°；LEFT为−90°；BACK为180°。
- 位置仰角α：相机相对产品基准点水平面的位置角，水平为0°，高于基准点为正，垂直顶拍为+90°；低于基准点为负。
- 光轴俯仰：另用文字写“向下瞄准产品中心”“水平瞄准前面板”等；只有相机确实瞄准同一基准点时，位置仰角才能直接对应俯拍幅度。
- 相机高度h：以台面或安装面为零，写明基准；基准点z₀通常取产品包围盒中心或目标结构中心。
- 相机滚转ρ：默认0°、画面水平；需要倾斜时注明“画面顺时针约10°”等，避免不同软件正负号混淆。

在瞄准基准点的简单设置中：h=z₀+r×tanα，r为相机与基准点的水平距离。仅用于实拍/3D机位规划，不用于从单张照片反推唯一机位。α=90°的顶拍单独定义，不套此公式。

项目使用其他坐标系时保留原定义并提供对应表；C4D等软件中的轴向与相机旋转值不得未经换算直接当作本规范角度。

### 5.3 产品常用拍摄角度

下表的角度只是定义与选用范围，必须有对应参考图或经确认的3D结构支持，不能据此自动生成未知面。A编号按每个产品自己的视角库分配，表内名称不强占现有编号。

| 视角名称 | 水平方位/位置仰角示例 | 主要用途 | 检查重点 |
|---|---|---|---|
| 正面平视 | θ=0°，α约0°，瞄准前面板 | 屏幕、控制区、正面识别 | 前面板方向、左右对称、不要误露未知底部 |
| 左前/右前三分之四 | θ约−30°至−45°或+30°至+45°；α约10°—30° | 主图、体积与材质 | 明确可见哪一侧，顶部占比与厚度符合透视 |
| 左/右侧正视 | θ=−90°或+90°；α按目标结构设置 | 接口、侧面轮廓 | 锁定物理侧及接口顺序，不用镜像造另一面 |
| 后侧视角 | θ接近±135°或180° | 后接口、接线方式 | 仅在后面已确认且允许展示时采用 |
| 高机位斜俯视 | θ依主题，α约35°—60° | 顶部图案、键位、桌面使用 | 上表面主导后，正面与厚度不能被人为拉长 |
| 垂直顶拍 | α=90°；记录画面上方对应FRONT或BACK | 配件平铺、顶部布局 | 光轴垂直台面，记录朝向；θ在正顶点不单独决定画面方向 |
| 低机位/轻仰视 | α接近0°或略负；视参考允许范围 | 体积、前面轮廓、场景强调 | 不为“有气势”露出未知底面或夸大体积 |
| 局部细节 | 方位服从目标局部的表面法向 | 接口、纹理、按键、接缝 | 必须说明裁切的是哪个真实部位，不能补造内部 |

“三分之四”是常见斜向展示称呼，不表示产品必须旋转精确75%或必有三面等面积。“轴测感”也不等于真实正交投影。

### 5.4 焦段、视场与镜头选择

以下均为全画幅等效焦段的内部建议。最终按产品尺寸、场地、允许视角、工作距离及构图调整；不要求为每张AI图写一组虚假的精确参数。

| 等效焦段/类型 | 适用方向 | 主要风险与控制 |
|---|---|---|
| 约16—24mm超广角 | 必要的大空间交代、特殊创意场景 | 近距离容易出现强烈近大远小；不作为小型产品保真主图默认方案，避免把主机放画面边缘 |
| 约24—35mm广角 | 客厅、零售店、人物与产品环境 | 保持合理机距；小产品不能贴镜头人为放大，检查边缘及垂直线 |
| 约40—60mm标准视角 | 中等场景、桌面、自然交互 | 在真实场景比例与主体识别间平衡；50mm不等于所有画幅上的固定“人眼视角” |
| 约70—105mm中长焦 | 小型电子产品主图、细节清楚的商业展示 | 可作为常用起点，配合较远机位和适当裁切；不靠焦距独自保证无变形 |
| 约105—200mm较长焦 | 更远机位、控制反射、局部与配件 | 场地和景深需另评估；过度平坦可能削弱厚度识别，不能误称正交 |
| 具近摄能力的微距镜头 | 小接口、颗粒纹理、键帽、铭牌 | 记录实际放大率、工作距离与景深；约90—105mm微距是可选起点，不是必选 |
| 正交相机（3D） | 确认模型的尺寸示意、平直结构图 | 无透视缩小；不能与真实透视商拍混写，不用于证明未经测量的真实尺寸 |

例如“85mm等效视角、适度机距、轻微透视”是表达目标；若真实参考来自近距离广角，不得只改提示词中的85mm就宣称已匹配。已有照片不能通过修改焦距标签改变其真实透视。

### 5.5 焦段、机距与透视的联动

透视关系主要由观察位置决定。固定视点和方向时，改变焦距主要改变取景范围；理想针孔投影下，广角中心裁切与较长焦的共同区域具有相同透视。实际镜头的畸变、对焦呼吸及画质差异需另看。

保持产品同样大小时，用较长焦通常需要后退；后退造成前后距离比例变化，形成较弱的近大远小与常说的“压缩感”。不能写成“只换长焦就压缩了产品结构”。

| 目标/操作 | 透视后果 | 正确处理 |
|---|---|---|
| 相机不动，只改焦距或裁切 | 主要改变画面范围，不产生新可见面 | 调构图并核对分辨率，不能假装已换视角 |
| 后退并加长焦，保持主体占比 | 前后大小差异通常减小 | 同时记录机距改变，不改变产品真实厚度 |
| 靠近并缩短焦距，保持占比 | 近端更突出、纵深感增强 | 谨慎用于保真图，不夸大前镜头、屏幕或机身宽度 |
| 相机上下/左右移动 | 可见面、遮挡及相邻边界改变 | 重新执行本图的视角结构锁定 |
| 后期把产品压扁以显得“长焦” | 人为改几何比例 | 禁止；回到正确素材或重新设机位 |

区分三类问题：近距离造成的透视夸张、镜头桶形/枕形等畸变、相机倾斜造成的线条收敛。校正应保留真实几何，不能一律把所有线强拉平行；俯视透视中远侧较小可以是正常现象。

### 5.6 景别、光圈、景深与对焦

景别按画面任务定义：环境远景解释使用空间；中景解释摆放与人物；近景完整展示产品；特写展示指定局部。不以焦段单独命名景别。

主图和参数图优先保证需要识别的轮廓、型号、接口及按键清楚；场景图允许背景虚化，但产品关键结构不因“电影感”失焦。背景虚化还可通过拉开产品与背景的距离实现，不必一律开大光圈。

| 类型 | 拍摄起始设置建议 | 对焦与验收 |
|---|---|---|
| 完整产品商拍 | 实际光圈可从f/8—f/11试拍，结合画幅、倍率和衍射表现调整 | 焦点放在需要覆盖的结构范围内，检查前后关键部位，不机械套“前1/3” |
| 产品生活场景 | 可从f/4—f/8试拍，按主体深度与人物信息调整 | 明确产品还是人物为主要焦点；产品用途不应被过浅景深遮蔽 |
| 微距局部 | 可从f/5.6—f/11试拍；不足时评估焦点堆栈 | 近摄景深可能很浅，不用f/22作为所有情况的默认解法 |
| 配件平铺/尺寸 | 让相机传感器平面与目标平面尽可能平行，匹配所需景深 | 多物品高低差仍需检查；不能只保证台面清楚 |

光圈数值越大通常表示开口越小，在其余条件相同时有利于增加景深，但过小光圈可能因衍射降低细节。景深还受画幅、拍摄距离、放大率、焦距及最终观看标准影响；不凭一句“f/8”保证全产品清晰。

焦点堆栈：固定产品、相机和光线，拍摄不同焦点的系列图，再合并清晰区域；检查透明件、反光边、细线缆、纸张和人物移动造成的重影、接缝与边缘伪影。堆栈不能拿来补造参考中不存在的细节。

3D渲染记录景深开关、对焦距离与光圈参数；无景深效果时可明确写“产品全域清晰”。AI提示词中的焦段与光圈仅为视觉引导，不能当作真实EXIF或物理精度证明。

| 任务 | 角度/景别建议 | 等效镜头建议 | 清晰与构图目标 |

### 5.8 参考照片分析与角度二次锁定

每张R参考先标“实拍已知参数 / 视觉估计 / 未知”。无EXIF和拍摄记录时，可以描述“中长焦观感、较弱透视”，不能断言“85mm、f/8、距离1.2m”。单张照片通常不能唯一还原焦距、机距和真实尺寸。

识别顺序：正常使用姿态 → 正面与物理侧 → 可见面主次 → 遮挡及线条收敛 → 相机方位/高度的合理范围 → 透视强弱 → 景别和焦点。反射不作为固定纹理，透视缩短不直接当机身比例。

每个可用角度保存独立卡：R参考、A视角、空间定义、机位、产品姿态、可见面、接口归属与顺序、Logo和纹理方向、遮挡、焦点、清晰范围、禁止展示面、证据状态。

更换机位后重新核对接口、标识和相邻边界。只改变画面裁切时，不冒称新物理角度。参考不足时保留已有视角，通过景别、位置和背景变化满足套图节奏。

### 5.9 实拍、3D与AI合成的执行边界

| 方式 | 需记录与控制 |
|---|---|
| 实拍 | 原始文件、可用EXIF、传感器画幅、实际焦距、机位与距离、产品姿态、光圈、焦点、光线、是否堆栈 |
| C4D等3D | 模型依据/版本、真实单位、相机投影类型、传感器/视场或焦距、机位与目标点、产品变换、景深；只渲染已确认结构 |
| 原图合成 | 产品原始透视保持，先匹配背景地平线、台面、视点高度、比例、光线与接触阴影；不直接以背景EXIF替代产品原机位 |
| AI生成/编辑 | 附真实参考、完整机位文字、可见面与局部约束；焦段只辅助控制观感；结果必须逐项核验 |

背景透视与产品冲突时优先换背景、调整机位方案或选择另一张真实产品参考；不扭曲主机来适应场景。3D渲染精美不代表模型事实已经核验。

## 15. 产品布光、材质与色彩管理

【强制】光照用于解释真实形体，不得改变固有颜色、表面工艺或掩盖接口与标识。先获得中性、可辨认的产品母版，再制作氛围版本。

### 15.1 布光记录与调整顺序

每个布光方案记录L编号、主光方位/高度、相对产品大小、软硬、补光方式、轮廓光、背景光、反光板/黑旗、白平衡基准及目标材质。与第5章相机卡分开记录；改变光线不等于改变机位。

【默认】先用一盏较大柔光源建立形体，逐步增加补光或黑旗，再决定是否需要轮廓光和背景光。每次增加一个变量，避免多盏灯互相抵消体积。固定曝光和白平衡后检查高光、暗部及原生文字。

| 组成 | 作用 | 检查点 |
|---|---|---|
| 主光 | 确定形体、主要阴影与高光 | 光源相对主体越大通常阴影过渡越柔；不能只按灯具瓦数描述软硬 |
| 补光/反光板 | 恢复暗部信息 | 保留明暗层次，不能补成无体积的平面 |
| 黑旗/负补光 | 控制杂散光，形成边缘与反射层次 | 不压黑到接缝、接口消失 |
| 轮廓光 | 分离深色产品与背景 | 不产生实物没有的发光描边或假透明壳 |
| 背景光 | 控制背景明度与层次 | 避免溢光污染固有色、白边和假光晕 |

### 15.2 不同材质的处理

| 材质/对象 | 起始方法【建议】 | 真实性底线【强制】 |
|---|---|---|
| 哑黑塑料 | 用明暗渐变呈现曲面，以窄而柔的反射区区分边缘 | 不整体提灰，不凭空加拉丝，不修成金属 |
| 白色塑料 | 保留高光与阴影的轻微层次，背景与主体分开控制 | 不让白壳过曝失去接缝，也不强染蓝灰 |
| 高光塑料/亚克力 | 通过柔光面及黑白反射面控制高光形状，先观察反射再移动灯 | 反射不能被当成印花；透明区域不能涂成实心 |
| 金属/拉丝 | 用连续反射梯度呈现形体，保留真实拉丝方向 | 不统一抹平纹理，不改表面粗糙度身份 |
| 玻璃/镜片 | 控制可识别反射，保留边界、镀膜色与厚度感 | 镜片反光不是发光；投影辉光遵守专项规则 |

## 23. 风格分类与决策方法

### 23.1 分类定位与使用范围

本章吸收《电商设计风格与高点击图片规则.docx》的31种风格，补充“按人群、任务和发布位置选型”的执行方法。原资料是风格参考，不是行业唯一分类、现行平台政策或已经验证的高点击公式。不同条目有重叠，暗黑模式等来自界面设计的概念需转为图片可用的配色方法。

【强制】先确定SKU事实、发布位置和要回答的购买问题，再选择风格。风格影响背景、构图、用光、文字及装饰；不能改变实物结构、材质身份、标识或功能。风格示例中的品牌、角色、软件界面不得直接借入当前商品。

【默认】每套确定一种主风格，辅以一种表达方法，例如“自然家居主风格+杂志式排版”或“克制科技主风格+写实商拍”。混合更多风格时说明统一依据，避免每张图像来自不同品牌。

### 23.3 选型与反选

Taste Skill的可用方法与条件化纠偏见第27章；不以字体、色相、对称方式或卡片形式的绝对禁令替代本节任务判断。

决策顺序：发布位置可用范围 → 消费者需求 → 本图证据 → 产品形体/固有色 → 场景与视觉语言 → 移动端表现 → 可制作性与成本。品类推荐只是候选，不代表“某品类只能某配色”。

| 已知需求 | 优先测试 | 避免机械套用 |
|---|---|---|
| 需要看清操作和接口 | 写实局部+简洁标注 | 浓重霓虹覆盖开口 |
| 不确定买回家怎么摆 | 自然家居+真实尺度 | 漂浮产品配抽象波纹 |
| 对材质工艺有疑问 | 准确细节+中性布光 | 全部改成金属高光 |
| 技术参数影响购买 | 清楚数据/概念说明+来源 | 无依据跑分、速度对比 |
| 新风格测试 | 固定SKU/利益点的不同视觉方案 | 同时改价格、文案、角度后只归因风格 |

【建议】未指定风格时提供少量有明确差异和选择理由的候选；完整纯提示词策划仍按第7章默认五种。单图改背景时无需重新展开31种风格。

**风格定位：深色环境承托高彩播放内容，以明确使用动作和功能示意呈现沉浸式影音体验。** 适合投影仪等影音产品；其他品类需重新判断。区别于单纯暗蓝背景加霓虹线框：播放内容、空间尺度和实际用途承担主要视觉表达。

| 维度 | 原图观察 | 可复用执行方法 |
|---|---|---|
| 配色 | 黑、深蓝、灰紫环境搭配橙红、金黄、蓝青内容 | 统一中性色与文字体系，允许不同卖点使用不同内容色彩；冷暖对比突出观看画面 |

## 24. 场景代入与真实使用叙事

### 24.1 场景必须回答的问题

【强制】用于使用说明的场景必须能回答：谁在什么时间/地点，因为何种需求，把产品放在哪里，怎样操作，看到什么结果。单纯把背景换成客厅不等于完成场景设计。人物不是必需；空场景也可通过产品摆放、操作结果与合理道具清楚表达用途。

【默认】填F10后再出图。场景元素只保留能解释需求、操作或体验的内容；投影仪可用晚间两人观影、个人耳机观看、小客厅桌面摆放等具体情境，但功能和姿态仍须有当前SKU证据。未确认防水、户外供电或耐候能力时，不以水边/露营等场景暗示这些能力。

### 24.2 真实场景与产品特写的两种尺度

| 表现方式 | 尺度处理 | 必查项 |
|---|---|---|
| 真实使用场景 | 产品、桌面、人物位于可信的同一空间比例 | 体积、前后层级、接触点、朝向与结果关系 |
| 产品特写叠加场景 | 放大产品作为独立展示层；背景为应用说明 | 用留白、层次或局部框架分开，不制造巨型产品摆在家具上的错觉 |

【强制】不因主图要大主体而在真实客厅里把18cm设备画成半米宽。场景中主机朝向、显示面/出光方向与使用结果需有合理关系；若特写层与场景不是同一视点，应明确图形层级，不能用强光束强行连接。产品与背景相互矛盾时调整场景或选择另一张已确认参考。

【强制】角色视线、手部接触、支架支撑、供电与线材符合使用方式。产品无需每图展示全部线材，但不能因此暗示无线供电或内置电池。软装不堵散热、饮品不贴通风面，操作姿态不凭空推定。

### 24.3 背景清晰度与色彩节奏

【默认】背景保留足以识别的场所、观看对象和人物动作，产品更清楚；不是把所有背景完全虚化。解释步骤/摆放时适当增加可读背景，材质特写时可减少环境信息。

【建议】套图使用统一中性色、字体和图标，在功能场景间改变明暗与冷暖：白天摆放可暖白/原木；夜间观看可深灰/暖灯；技术说明可中性背景加少量品牌色。不是每张都橙黄，也不是每张都冰蓝。白平衡和环境光不能把真实枪灰壳变成金色、银色或绿色。

### 24.4 递进叙事与消费者疑问

在固定09尺寸/10包装的框架下，01—08围绕实际疑问组织，而非机械每张重复参数。常用路径：是什么/适不适合我 → 核心利益与证据 → 怎么操作 → 在家怎么用 → 连接/兼容/限制。图02总览可作导航，但不替代后续图解释。

信任内容优先采用真实结构、清楚规格、销售内容和有依据的服务说明。认证、口碑、销量、物流、保修与促销均须有证据且适合发布位置；不为叙事完整编造评价或认证。

### 24.5 场景验收

- [ ] 不看标题也大致知道产品在什么场合使用。
- [ ] 人物、操作、摆放与功能有联系；无人物时环境与结果足以表达。
- [ ] 真场景尺度可信；展示特写与场景层次没有混淆。
- [ ] 投影/显示区、设备朝向、支撑和供电逻辑不矛盾。
- [ ] 背景可识别但不抢焦点，文字仍可读。
- [ ] 家具/音频设备等道具没有被误认为随箱赠送。
- [ ] 未通过场景暗示未经确认的防水、续航、户外或兼容能力。

## 25. 图片效果测试与成本闭环

“高点击”是目标或测试假设，不是本规范能事先保证的结果。清晰、合规、准确和真实使用表达是制作质量要求，实际点击/转化还受渠道、位置、人群、价格、活动、季节等影响。

### 25.1 先写假设和比较变量

【默认】从2—3个可区分的方案开始，例如“自然摆放能否比抽象科技背景更容易让目标用户理解用途”。记录唯一主要变化、保持项和预计观察的指标。必要时可测一组整体创意，但结论只能归因到组合方案，不能声称由某一种颜色单独导致。

用户只要求设计时，交付可测试方案即可；未经明确授权不自动投放广告、修改商品图或产生广告费用。平台原生分流工具可用时按其规则执行；否则明确测试方法与局限，不把错时轮换当作严格随机实验。

### 25.2 指标与口径

| 指标 | 简单定义 | 判断边界 |
|---|---|---|
| CTR 点击率 | 点击÷曝光 | 记录有效点击/曝光定义、位置与时间 |
| CVR 转化率 | 归因订单÷对应点击或访问 | 必须写清分母、订单状态和归因窗口 |
| 每千曝光订单 | 归因订单÷曝光×1000 | 只能在同一归因口径下比较 |
| 误解反馈 | 不符描述、兼容疑问等实际反馈 | 不凭个别意见推断所有用户 |
| 成本 | 设计/修图时长、生成次数和实际费用 | 有数据才计算单图成本及节省比例 |

点击率升高但转化降低时，不直接判为胜出；检查图片是否吸引了不匹配的人群或夸大结果。不能用图片测试证明功能或认证真实。

### 25.3 测试纪律与结果表达

【强制】记录市场、SKU、人群、位置、价格、活动、库存、时间及重要变化；不把不同市场/活动下结果直接归因风格。测试前写观察期、主要指标及停止条件，避免看到短期上涨就提前宣称成功。

不规定所有产品统一“曝光1000即有效”“CTR超过某值必胜”等阈值。样本量与不确定性取决于基准、差异、分流和业务要求；没有足够数据时结论写数据不足。使用统计工具时记录方法与假设，不编显著性。

【默认】结论使用“本次条件下表现更好/未见明确差异/数据不足/需重测”；不得推广成所有产品、平台或时间通用法则。赢家方案保存版本和适用范围，下一轮只针对仍未解决的问题。

### 25.4 正误案例与复杂度

建立F12案例，优先记录真实出现的接口错面、遮罩变屏幕、遥控器改键、灰壳金属化、巨型产品尺度、抽象背景看不出用途等问题。只有示意案例时明确写“教学示例”，不能冒充实测或真实投诉。

| 任务级别【默认】 | 例子 | 最小记录 |
|---|---|---|
| 轻量 | 改一句宣传文案、换背景但不变机位 | 原底版、修改/保留区、受影响证据、复查结果 |
| 标准 | 单SKU一套图 | 任务、参考、锁定、摄影、证据、图序、质检及必要场景卡 |
| 复杂 | 多SKU、多平台、多语言/风格、多人交接 | 标准项+变体映射、测试/成本、关联版本与交接记录 |

### 27.6 “反模板化”执行流程

1. 定本图任务与证据：引用F05、F06及F13，明确核心利益与允许角度。
2. 检查重复来源：是否同一标题位置、同一产品占比、同一房间、同一湖景、同一后视角、同一灯带被连续复用。
3. 选择有意义的变化：可换景别、焦点、文字组织、内容颜色、人物动作或信息分组；不要求每项都换。
4. 写清保留项：品牌体系、字体层级、图标、边距、外观与事实。角度变化必须有对应原始参考。
5. 为每个装饰写用途：解释功能、分组信息、引导视线或营造用途相关氛围；无用途则删。
6. 生成后按真实成图检查：是否更易理解、是否丢失主体、是否出现假窗口/接口、标题是否变得吵闹或说明过小。
7. 记录调整结果：通过/修改/待核实，写具体发现；不以“更高级”“更像大牌”独自作为通过理由。

这是制作检查，不是新增审批步骤，不要求每张都停下来询问。轻量任务可以直接引用已确认控制卡，仅记录变化与复查。
