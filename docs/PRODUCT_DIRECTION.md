# 产品方向

以下为依据 SOP 与现有代码提出的设计方向，尚未实现。

## 定位与形态

映序 Studio 是面向电商商品的 AI 视觉生产工作台。建议以网页工作台作为主要入口，支持本机或自托管服务；后续再决定是否封装桌面程序。

工作台提供两种操作空间：电商生产区面向资料、策划、制作、审核与交付；工作流区面向专业用户编辑、验证和调试 ComfyUI 工作流。两区最终共享项目、SKU、素材、任务、版本与输出记录。

ComfyUI 与 ComfyUI Desktop 作为可连接的执行端。专业用户可以保留原生节点编辑体验。能否接通 Desktop 必须通过连接与真实执行验收确认。

## SOP 驱动的生产过程

1. 选择工作类型：资料整理、套图策划、仅提示词、实际制作、局部修改、质量验收。
2. 归档真实商品、配件、包装及风格/场景参考；记录素材用途、所属 SKU 与出处。
3. 将外观、材质、尺寸、接口、结构、配件、可见面及未知项转为可确认事实。用户校订后冻结本次任务快照。
4. 形成套图计划：每张图绑定目标、证据、文案、角度、制作方式与交付要求。
5. 按槽位制作、保留版本，对照商品证据验收；关键商品不一致必须拦截。
6. 只交付已验收的独立文件，并产生交付清单；仅在确有源工程时提供可编辑源文件。
7. 将通过验收的方案、失误原因与真实营销反馈回流到案例库。

## 需要保留的业务规则

- 商品身份、SKU、结构和真实证据优先；未知项保持未知，不能由风格或模型猜测填补。
- 默认十槽位为策划起点，可按任务调整。尺寸图需已确认尺寸，包装图需 SKU 清单及视觉参考；缺项只阻塞受影响槽位。
- F01–F14 是共享数据的渐进式记录，不应直接变成十四道批准关卡。
- 五风格乘十图的默认展开用于完整提示词模式，不能直接触发五十次付费制作。
- 原图不可变；事实、策划、工作流、模型及输出各自有版本与依赖关系。
- 执行成功、质量通过和交付完成分别记录。商品一致性不能被审美评分抵消。
- 保留合成、局部编辑、已验证 3D、AI 背景、受约束重绘、矢量排版和人工导入等路线；反复关键失败时切换路线。
- 1600 方图、sRGB、JPEG、小于 3MB 可作为内部可配置导出默认值，不视为全部平台统一规定。
- 风格索引不等于已验证案例库；真实营销结果才能进入效果回流，不自动发布或投放。

业务规则细节以 `docs/sop` 内 V1.3 原文为依据；平台要求需按站点、类目和实际使用时间核实。
