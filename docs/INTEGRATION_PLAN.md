## 目标分工

- 电商平台提供已有产品、原图理解与校订、报价快照、任务持久化、事件与供应商调用基础。
- ComfyUI 架构师提供工作流规划、编译、校验、模板与专业编辑基础。其校验缺陷先修复。
- 新增业务层承载 SOP 的项目/SKU/事实/套图/槽位/质量/交付模型。
- 新增连接层将业务任务转换为执行端请求，保存实际执行 ID、输入输出映射与原始回执；状态不明时不得盲目重复付费提交。
- 原有数据库迁移和配置先保留在子工程内，待明确数据模型与迁移方案后再变更。不能仅复制两个 TaskSpec 名称就认为语义已经统一。

## ComfyUI Desktop 验收范围

验证实际安装版本、服务地址与端口发现、访问控制和来源约束、模型及节点能力、输入文件映射、输出取回、多个页面或客户端并发、断线/重启恢复及未知执行状态。

当前没有可交付的 Desktop 连接器，不能把已有网页脚本调用 `/prompt` 当作业务闭环已接通。
