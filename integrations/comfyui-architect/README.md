# ComfyUI Workflow Architect 2.15.2

中文需求 → 本地知识/离线 AI 或受控大模型规划 → 本地校验 → 人工图片/模型绑定 → 真实 ComfyUI 工作流。包含电商提示词库、六模块详情页与品牌首屏辅助；复杂换装和商业画质仍需逐项验收。

**项目状态与交付范围见 [2026-11-16 项目报告](docs/PROJECT_REPORT_2026-11-16.md)**；发布测试见 [验证记录](docs/RELEASE_VALIDATION_2026-11-16.md)。真实付费 API 默认关闭。知识库不是自动训练，导出方案不是已执行图片。

### 当前版本快速开始

1. 将本仓库放到 `ComfyUI/custom_nodes/ComfyUI-WorkflowArchitect`。
2. 保存现有工作流，由本人重启 ComfyUI 并刷新浏览器，确认面板显示 **2.15.2**。
3. 从“知识与环境验收”检查节点与模型；缺失依赖先诊断。生成后人工核对图片、模型、提示词和尺寸。
4. “导出 ComfyUI 工作流 JSON”得到画布文件；“API 任务 JSON”和第二阶段规划记录用途不同。先保存原画布，再插入并明确批准运行。
5. 离线 AI 为单独部署的 CPU 服务，不随仓库附带权重或自动启动；按 [部署说明](docs/offline-ai.md) 检查固定路径后使用。

开发验证：`python -B tools/run_checks.py --report release-validation.json`。便携 Python 也可运行该入口；需 Node.js 和测试使用的 Pillow / aiohttp / cryptography，脚本不自动安装依赖。模型、用户图片、密钥和运行数据库不随代码发布。

## 历史 2.2.2 基线说明（以下并非当前版本快速入门）

界面名称：**AI 工作流架构师 2.2.2**  
版本：**2.2.2**

这是一个离线优先的 ComfyUI 扩展。它把中文需求转换为结构化任务，扫描当前
ComfyUI 的真实节点和模型选项，生成分阶段方案，选择兼容的已验证模板，完成静态
校验后再由用户确认插入画布。2.1 将“工作流创建”和“工作流执行”分离：缺少节点
或模型时仍创建草稿，并通过 Manager 修复闭环逐步恢复为可执行工作流。

插件不调用云端 AI、不上传图片、不执行需求文本中的代码。它会结合 ComfyUI
Manager 匹配缺失或不可用节点，并建议安装、启用、修复、更新或替换；改变本地环境
的操作仍必须由用户确认。

## 安装或从 1.0 升级

1. 关闭 ComfyUI。
2. 备份旧目录（可选）：

   ```text
   ComfyUI/custom_nodes/ComfyUI-WorkflowArchitect
   ```

3. 用 2.2.2 安装包中的同名目录覆盖旧目录。
4. 启动 ComfyUI，浏览器执行一次强制刷新（`Ctrl+F5`）。
5. 确认右下角出现“AI 工作流架构师 2.2.2”按钮。

2.2.2 本身无新增 Python 运行时依赖。电商详情页会使用 ComfyUI 的背景移除节点、
本地 BiRefNet 权重以及 `ResizeMask`；缺失时可通过 Manager 诊断并修复。

## 使用

1. 点击右下角“AI 工作流架构师 2.2.2”。
2. 输入需求，选择商品/参考图，并选择“稳定模式”或“低显存模式”。
3. 点击“解析需求”，确认识别出的任务与分辨率。
4. 点击“生成方案”。无论依赖是否完整，插件都会尽量创建完整工作流或草稿。
5. 如果存在缺失节点，点击“诊断并优化节点”，复制候选包名称并打开 Manager。
6. 在 Manager 中选择安装、启用、修复或更新；完成后按提示重启 ComfyUI。
7. 点击“刷新并重新构建”。依赖完整后，草稿会升级为可执行工作流。
8. 草稿可“导出 JSON”；验证通过后还可“插入画布”。

示例：

```text
生成一张未来城市夜景，输出 1024×1024
参考这张图片生成油画风格，输出 768×1024
参考这张商品图制作电商详情页主视觉，生成奶油白影棚场景，保持商品结构和 Logo，输出 1024×1536
用蒙版局部重绘天空
把图片调整尺寸为 1280×720
用模型高清放大图片
给模特换上这件上衣，脸和发型不要变化
```

图片类任务可以在面板中直接选择 ComfyUI `input` 目录内的图片。电商详情页会按所选
图片的真实宽高计算缩放和居中位置；插入后若更换 `LoadImage` 图片，请重新生成方案，
避免沿用旧图片的版式。局部重绘仍使用图片自带的蒙版/Alpha 通道。生成类任务会自动
选择当前 ComfyUI 列表中的第一个基础模型，用户可在插入后更换。

|---|---:|---:|---|
| 文生图 | 是 | 是 | ComfyUI 核心节点、checkpoint |
| 图生图 | 是 | 是 | ComfyUI 核心节点、checkpoint |

捏造可执行换装图。视频、多人换装、自动质量评分以及第三方许可证自动判断暂不支持。

## 低显存模式

- 超过约 100 万像素的需求会按原比例缩小到 8 的倍数。
- 默认采样步数从 24 降至 16，批次数固定为 1。
- 文生图和图生图使用分块 VAE 编解码；局部重绘使用分块 VAE 解码。
- 图片放大使用 Lanczos，避免加载超分模型。

低显存模式降低显存压力，但不能保证所有 checkpoint 都能在任意显卡上运行。
