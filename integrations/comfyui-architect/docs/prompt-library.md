入口：AI工作流架构师 → AI提示词库 → 读取提示词库。当前24张本地原创制作卡，不是新下载模型、在线爬取库或已训练本地小模型。

## 覆盖范围

- 主图与场景4张：客厅首屏、影棚背景、空桌面、白底编辑。
- 详情页卖点7张：容量、处理器、语音、多屏、接口、尺寸、配件。
- 精修与编辑4张：材质、蒙版清理、光照、风格参考。
- 人物与换装5张：整套/上衣/下装替换、专业VTON角色核对、授权成年模特场景。
- 视频3张：商品轻推、生活方式单动作、场景B-roll。
- 整套规划1张：逐页事实、素材、提示词、文案与检查清单。

## 使用方法

1. 读库后按分类/关键词筛选；先看素材角色与适用用途。
2. 修改变量示例。参考编辑卡明确图1/图2角色；整套换装不是衣服改色。变量每项1至240字符，必须填全，不接受额外变量、花括号或控制字符。
3. 点击“填写并生成可复制提示词”，手动复制到**实际支持的**文本端口。negative仅在实际模型支持时使用，不会自动接线。VTON无文本端口时，不向该节点强塞提示词。
4. 可导出提示词资料JSON（不是ComfyUI节点工作流），包含版本、库SHA、填写变量、素材要求、正负提示及验收项。用户填写内容会随导出保存，不要填写凭证或敏感资料。

layout-only / planning-only / vton-input-only 是排版、规划、输入核对说明，不应送入采样器。精确商品、Logo、接口、参数、英文文字与图标优先使用真实素材与确定性排版；提示词不保证保真。区域外严格不变需原图合成及独立差分。视频时长由实际frames/fps设置，不由文案指定。

## 与现有功能的关系

新增卡片纳入本地知识检索，但仅为reference-only，不能升级为编译模板、当前模型能力或执行许可。原82条文档完整保留，另增24条，知识集SHA相应变化，旧规划摘要需要重新读取。库没有来源网页认证，均标记assistant-authored；不虚构供应商文档或效果已验收。

库和生成接口：POST `/workflow-architect/prompts/search`，输入可选query/category/engine；POST `/workflow-architect/prompts/render`，输入id/expected_sha256/variables。只处理内置卡片，不接受路径、URL、任意模板或执行参数，不请求API、不读取图像、不排队、不写用户资料库。库变化时拒绝旧摘要填写。SHA仅追踪版本，不是权限。

UI无启动请求，显式读取；30秒取消、有界512KiB/4096非空分片严格UTF8，关闭/换卡/改变量清掉旧输出、拒绝迟到结果。不写localStorage、不自动复制剪贴板、不自动带入旧规划或执行页面。后续自动接入编译器前仍需具体模型/节点端口绑定与实测，不能把“能复制提示词”称为全自动详情页完成。

V3建议顺序：客厅背景＋空桌面→品牌首屏精排；内存/芯片/语音背景配真实产品；接口/尺寸/配件采用原图排版说明。只用已核实规格，不照抄参考中的Android14/4K60FPS、认证或未测对比。原首屏视觉验收独立保留，不因提示词库测试通过自动通过。
