# v2.5.0 Klein双图换装（实验）

此独立入口编译23个原生节点，不自动提交任务，不下载模型，不消费付费API。
两次本机Klein4B小样可运行不代表商品花纹/身份/手脚/背景保真，非像素保护。普通解析入口仍不自动回退换装。

1. 更新后重启ComfyUI，浏览器强制刷新，确认标题v2.5.0。
2. 在ComfyUI上传人物原图和服装平铺图到input。打开插件“Klein双图换装（实验）”。
3. 检查依赖并刷新图片，明确分别选择图1人物/图2服装，不默认用第一项或同一张。
4. 填写服装结构/颜色/花纹要求（建议英文），确认素材权利/成年人物及实验限制。
5. 编译不运行。可导出JSON，或保存现有画布后确认替换画布；检查双图与完整提示词后手动排队。

固定模型：flux-2-klein-4b-fp8.safetensors、qwen_3_4b.safetensors、flux2-vae.safetensors；不自动换模型。匹配节点选项并不证明任意机器上的文件SHA或显存适足。当前本机主权重实际SHA已验证；接口不加载模型校验SHA。
固定CPU文本编码、Euler4步/CFG1、576×768、单张（后端允许16倍数/256至1024且至多786432像素）；参考图按输出尺寸缩放，非3:4图可能拉伸，请人工裁切/检查。没有批量执行/硬像素锁定；胸部和私密部位固定要求不透明内衬，提示词不是模型输出保证。

HTTP：POST /workflow-architect/people/tryon/prepare，默认仅依赖/选项检查；显式build_draft与当前expected、两图、固定模型映射和授权才编译。未知字段、同图、过期清单、缺依赖失败关闭，不下载/重试/排队。窗口关闭/改输入取消旧回调并清旧草稿；手动插入会替换当前画布，必须先保存。

验证：156项Python单元含12项新分支，26项mock DOM场景含7项新面板，实际当前8188节点清单静态编译valid。不是实际浏览器验收；重启后需核当前HTTP入口与界面。此前两次研究推理不计作插件接线后的运行验收。
