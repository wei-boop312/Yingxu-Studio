# 本机凭证（Windows）

仅本人在本机交互终端输入新密钥。先在供应商网站撤销曾暴露的旧密钥；不要发送给聊天、写进工作流、提示词、导出文件、命令参数或环境变量。

使用便携 Python 运行插件目录 `tools/configure_credential.py --root <ComfyUI实际用户目录>/workflow_architect/credentials --store`。脚本两次隐藏输入，不支持从管道、文件或参数传密钥。首次目录须空；不更改其他目录权限。已有凭证须明确加 `--rotate`，保留旧密文备份。无 `--store` 时仅显示存在状态，不解密。

Windows当前用户DPAPI加密，绑定已批准Hubway/gpt-5.5/Responses目标；目录取消继承，仅当前用户和SYSTEM。磁盘只写密文，不把本机凭证加入插件安装、工作流或导出。状态不代表密钥有效，保存不启用联网。宿主仍须显式注入 `vault.read` 凭证端口和可信CostGuard，缺价格与单次限额证据保持关闭。

边界：同一Windows用户下恶意代码仍可能解密，管理员/备份/内存攻击不在本方案保证范围；Python字符串不能保证可靠擦除。不要将整个用户凭证目录同步、打包或分享。仅自有临时假密钥完成DPAPI实测，没有读取或配置用户真实密钥。
