# 六模块详情页（2.10.0首版）

## 2.11.0详细提示词与多角度

每模块可带visual_prompt对象：positive详细英文背景提示（最多1800字符）、negative禁用元素（最多1200字符）。系统导出的GPT指令包含该格式；不接受任意工作流/节点/命令字段。完整提示词进入该模块实际背景CLIP节点与画布widget，不再被通用中文场景转换器覆盖；商品分支原图保留策略不变。视觉描述不是事实证明，文字事实仍仅引用用户事实ID。

可分别选择hero/benefits/details/scene/specs/closing的原图，未选时沿用主图。明确绑定完整六项，仍核当前LoadImage真实选项与实际尺寸。提示词或任一原图变化会改变批次摘要，不能混用旧进度；上下文合同版本升级，旧2.10方案须重新导出。原无visual_prompt的本地草案继续走原场景转换器，不伪称自动获得详细美术指导。

V3六组详细提示词已由当前助手根据用户报告编写并编译校验，没有调用站点GPT API。外部API仍须原凭证/可信费用批准；六段长提示词可能超过当前输出token上限，截断时拒绝，不自动加token/费用或重试。人物只生成背景成人场景，未实际运行验收；遥控器和完整配件版本不明暂不放入新首屏。

新首屏实际紫黑背景相比旧黑影棚更接近方向，但仍出现被禁止的底座与悬浮感，商业质量未过。不能把提示词传递测试、schema、hash或实际success当成视觉验收，不保证仅凭提示词消除幻觉或保证Logo像素一致。尚缺确定性布局约束、专业细节/规格/配件版式及实际浏览器新版本验收。

入口：AI工作流架构师 → 六模块详情页。先保存当前画布；此入口不替换画布，只有导出工作流。

1. 输入商品名称、真实资料（每行一条，最多12条，每条100字），不要密钥/私人资料。规格、材质、功效、价格不推断，须用户提供且自行核实。
2. 读取环境并生成六模块草案。可直接用本地草案；或导出完整提示词交GPT，粘贴严格JSON后校验。可选择已配置的可信API规划，依旧受原凭证/真实费用上限批准，默认关闭，不读取ChatGPT登录、不上传图片、不绕过0.02USD批准。
3. 人工检查事实编号/场景、明确选择当前原始商品图、checkpoint和抠图模型，确认后编译六份含真实节点连线的工作流。导出任务包不是画布文件；各模块workflow.json才可导入ComfyUI。
4. 确认连续运行：512×640，每张双分支，共最多6任务/12采样；一次只提交一张并等待实际history。须开始时队列空闲。开始后其他客户端仍可排队，不是全局独占GPU。
5. 全部完成后核对输出，导出768×6720长图或六张原始分图。文字由canvas绘制，不让模型写中文。文案超出固定标题区拒绝导出、不静默裁掉，请减少每模块事实。浏览器可能拦多文件下载，需本人允许。离线工具export_detail_page.py为自有已完成任务包提供Pillow确定性排版，不读取远程图片。

## 精确能力范围

商品展示/卖点/细节/场景/规格/总览六个固定模块；首版图片均为现有商品抠图+场景合成，模块事实可不同，但不含自动微距取景、自动爆炸图、专业规格表、多SKU或系列拍摄一致性保证。默认草案重复引用已提供资料，须人工分配；这是可落地初版，不是高质量商业详情页已验收。

GPT只可输出有序模块id、事实ID和六种受控场景，不能生成新广告事实、任意节点或运行命令。API真实调用须显式宿主配置、单次授权与可信CostGuard，和本地GPU生图两条独立路径，不自动外发。

## 进度和失败

每次提交前写浏览器本机16KiB进度指针并回读；失败不POST。提交结果丢失/缺id/未知时停止，不能自动重投。指针不包含密钥、图像Base64或完整工作流，只存批次摘要、模块状态、任务编号和输出关系，不是服务器权限凭证。

刷新/关闭只停后续提交，不取消已交任务。重新填相同资料、同方案和相同图片模型并编译，点“只读恢复”读取实际history，再点连续运行可继续ready模块，done不重跑。指针绑定实际API图摘要，换原图/模型不能混入旧批次；相同扫描不因UI元信息流水号失效。已明确error模块可人工批准一次重试，保留旧编号；unknown/submitting/历史缺失不支持此重试。限制是本机操作护栏，不是防恶意用户篡改的费用授权。

长图/分图导出前再次核实际服务器history/输出编号；图片尺寸必须512×640。进度无法跨浏览器/设备自动恢复，没有服务器队列数据库或正式断点事务；清浏览器存储可能失去恢复关系。不要随便清指针；清理不会取消任务或删除输出。图像缓存、浏览器、服务端不是全局ACID。
