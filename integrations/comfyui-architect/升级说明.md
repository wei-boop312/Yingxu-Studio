# AI 工作流架构师 2.15.2 安装与升级

1. 保存现有画布与工作流，备份旧插件目录。
2. 将本仓库放入 `ComfyUI/custom_nodes/ComfyUI-WorkflowArchitect`，目录内直接应有 `__init__.py` 和 `web/`。
3. 由本人重启 ComfyUI 并刷新，确认按钮与健康接口显示 **2.15.2**。
4. 先检查环境依赖，再明确选择图片/模型、提示词和尺寸。画布 JSON、API 任务 JSON 和规划记录用途不同；插入前保存当前画布，运行需明确确认。

离线 AI 为独立 CPU 服务，不随仓库附带模型/程序，不自动部署或启动。当前工具沿用 Windows 固定目录，换机前先阅读 [部署文档](docs/offline-ai.md) 并适配路径。不要将用户 input/output/user、密钥、运行数据库或模型混入源码。

当前状态见 [项目报告](docs/PROJECT_REPORT_2026-11-16.md)。复杂换装仍为实验能力，真实付费 API 默认关闭，整体商业画质尚未验收。开发检查可运行 `python -B tools/run_checks.py --report release-validation.json`。

以下保留 **2.2.2 历史说明**，不是当前版本的功能或安装状态。

## 升级方法

1. 关闭 ComfyUI。
2. 用 2.2.2 的 `ComfyUI-WorkflowArchitect` 文件夹覆盖
   `ComfyUI/custom_nodes/ComfyUI-WorkflowArchitect`。
3. 重新启动 ComfyUI。
4. 浏览器按 `Ctrl+F5` 强制刷新。
5. 在右下角确认出现“AI 工作流架构师 2.2.2”。

2.2.2 会在节点或模型缺失时保留草稿工作流。请使用“诊断并优化节点”查询 Manager，
在确认安装、启用、修复或更新后重启 ComfyUI，再点击“刷新并重新构建”。

## 主要变化

- 电商详情页使用独立的英文背景提示和商品保真提示。
- 自动使用本地 BiRefNet 为透明 PNG、JPG 等商品图生成前景蒙版。
- 商品和蒙版同步等比缩放并自动居中，商品分支默认降噪为 0.15。
- 面板可直接选择本次编译使用的商品/参考图。
- 可识别文生图、图生图、局部重绘、调整尺寸、图片放大和单人上衣换装。
- 低显存模式已可用。
- 缺节点时先显示方案，再通过 Manager 查找候选组件。
- 基础任务可以直接编译、验证、插入画布或导出 JSON。

## 注意

- 电商任务应先在面板选择商品图；插入后若更换图片，请重新生成方案以重算版式。
- 自动抠图仍需人工核对透明边缘，尤其是玻璃、毛发、细线和反光材质。
- 插入的生成类工作流默认选择当前模型列表中的第一个 checkpoint，可自行更换。
- 换装仍需要安装并验证匹配的第三方换装与分割节点；插件不会自动安装。
- 第三方节点与模型的许可证需由使用者确认。
