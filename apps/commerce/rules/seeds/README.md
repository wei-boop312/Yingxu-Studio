# 未验证平台种子

这些文档只声明范围及历史草稿版本，不包含未经核实的现行政策阈值。三个平台均为unverified、规则不完整，不得自动compliant。通过scripts/rules.py publish可导入；不能直接把evidence_status改成verified，必须另行完成证据核验、私有归档和新版本发布。

新任务范围按原执行包固定为Amazon、Temu、Ozon；当前UI显式使用Amazon US、Temu US、Ozon RU，种子分别采用相同站点。旧eBay/Shopify种子从新安装清单移除，0026不删除或改写数据库历史规则/任务。域名白名单仅限制证据来源，不证明政策已核验。
