# V4 平台范围修正

原始执行包 `task-create.schema.json` 明确要求 `amazon / temu / ozon`。早期实现误用了 `amazon / ebay / shopify`，此前 CI 绿灯只证明当时实现，不能证明这一原始要求已经满足。

新任务、规则发现API、规则文档及发布函数统一为Amazon、Temu、Ozon。前端显式选择Amazon US、Temu US、Ozon RU；Ozon规则查询默认RU，其余默认US。规则站点仍可通过API参数明确指定，不把某一站点规则套用到全部国家/类目。

迁移0026仅替换受限规则发布函数的允许平台和证据域名；保留原函数所有者及ops_admin权限，不删除或修改任何历史任务、规则、报告或钱包。旧eBay/Shopify草稿保留图片、提示词与保护矩形，但清空平台选择，要求用户重新选择，不能静默改成另一个平台发起任务。

Temu/Ozon种子没有推测的白底/像素/占比阈值，均为unverified、不完整，结果仍manual_review。证据域名白名单只是发布来源约束，不证明取得了官方政策正文或全部规则可以自动判断。原始计划和执行包文件保持不变。

单元直接读取原始执行包枚举，验证API模型与三份种子一致，并覆盖证据域名伪装及错误平台来源。新增原生用例验证三平台发现/发布/报价/真实PG和S3的Fake交付/各平台报告，以及直接SQL拒绝旧平台和伪装证据来源。生产浏览器用例选择三平台、恢复旧草稿、验证重新选择、刷新与确切US/US/RU提交参数。候选必须通过新提交的完整CI后才算这些原生行为已验证。
