# AI 自动总结外观：前置步骤

在工作台选择商品原图，点击“AI 理解产品外观”。先获取费用说明，勾选确认本次独立付费识别与原图传给百炼，再执行一次识别。该步骤使用现有已授权qwen3.8-flash；不会生成图片，不扣平台积分，供应商按实际Token计费，实际金额仍待账单核实。离线模式不伪装AI识别，入口禁用，可继续手工填写。

AI草稿包括连贯外观文字、颜色分布、可见材质纹理及不确定项。请对照原图修改形状比例、部件关系、标识和描述，勾选校订确认，保存为外观资料并用于重绘。确认后选择文字参考模式（不回贴像素），不用画保护区；已有选区草稿仍保留，后续可自行重新选择像素工具。

确认资料绑定原图版本及识别编号，重复确认不会新增资料；修改已确认文字请使用原工作台“编辑资料”。选择另一原图时，服务器拒绝沿用不匹配的AI资料。生成报价保存确认后的资料版本；实际生成提示词包含描述、颜色和材质，内部来源ID不发给模型。此功能提高一致性，不保证外观零偏差；专门的成品外观一致性检测仍待后续实现。

## 请求、回执与恢复

迁移0068增加租户隔离的appearance_understandings。报价10分钟有效，提交必须携带真实供应商确认头，核对运行版本和当前授权。提交状态在网络调用前提交至PG；同一识别编号仅能POST供应商一次，同原图的未确认请求阻止新识别。原始HTTP正文、状态与请求摘要仅存在私有LIVE_PROVIDER_PRIVATE_DIR/appearance-understanding中；业务表保存摘要、解析结果、计量与原图摘要，实际费用为null而不是0。默认适配器只能接受显式MockTransport，真实传输必须live=True且不可混入Mock。

刷新识别记录会读取现有状态；若已归档HTTP200原始响应，可通过recover端点从原文恢复草稿，不调用供应商。无响应、超时、截断、数组、错误模型或不合法结构不会生成假摘要，保留uncertain。明确4xx拒绝保留原正文并标failed。没有原始回执时需管理员核对；不伪造响应，不自动重发。

管理员核对后若决定关闭未完成交付，可使用专用非owner ops_admin：

```powershell
python scripts/admin.py close-understanding --user USER_UUID --understanding UNDERSTANDING_UUID --operation-id NEW_UUID --reason "核对依据及关闭理由，供应商费用仍待核实" --evidence-digest SHA256
```

此操作追加审计，仅关闭交付，不宣称供应商退款。原回执私有目录需独立备份；现有离线备份演练工具不收集真实供应商私有响应，不能当作本功能的完整线上灾备。
