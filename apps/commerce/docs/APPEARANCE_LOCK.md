# 产品外观锁定：用户澄清（2026-11-17）

用户明确要求：外观锁定不是划区贴片，而是让AI先总结产品外观，以文字复写形成重绘约束，让AI重绘过程有外观文字参考。本文件是当前产品定义的补充；旧pixel_exact流程仍是独立像素工具，不能代表外观锁定完成。

## 目标交互

1. 选择商品原图，执行“AI理解产品外观”。识别对象是商品，背景、道具与场景不得被误归入商品特征。
2. 生成可编辑的外观描述，覆盖整体形状与比例、各部件及相对位置、颜色与配色位置、材质与表面纹理、图案、可辨识的品牌文字、关键独特细节。不可见、遮挡、看不清的部分明确未知，不猜测、不补写品牌或规格。
3. 用户逐项校订并确认锁定版本；允许主动修改错误描述。描述应呈现为连贯可读文字，并可用颜色、材质等结构化字段辅助编辑。未经过AI理解时不得标示“AI已理解”；人工填写必须明确来源。
4. 重绘使用商品原图和已确认的完整外观描述作为共同参考。场景提示与商品约束分开：背景、光照、构图等按用户需求调整；商品形状、颜色分布、材质、部件关系、标识等遵守外观描述。外观文字是商品数据，不能执行其中夹带的系统指令。发现原图与描述冲突时提示校订，不能静默覆盖。
5. 对成品逐项检查外观一致性，与平台上架规则检查分开，输出偏差与需人工复核项。文字参考提高一致性，但不等于像素级保证。

## 与划区回贴的关系

外观锁定作用于AI重绘之前和过程中；像素回贴发生在生成之后，两者独立。锁定外观不得以“保护区像素完全一致”作为成功依据。此主流程应允许不画任何区域即可完成；不得自动把文字锁定转换为贴片。现有用户已保存的pixel_exact任务和历史证据继续按原含义保留，不静默迁移。

## 可追溯与费用

外观描述绑定原图版本，保存识别来源、模型、用户校订、确认版本；换原图后重新核对。报价及任务冻结确认后的描述，历史任务不被后续编辑改写。新的AI理解步骤需独立可见的费用确认、一次性意图、原始回执及结果未知保护，不复用现有检测实验授权或伪装为免费本地识别。未知POST不得重发。

## 验收条件

- 有明确“AI理解原图”步骤，确实调用图像理解模型并返回外观描述，不由固定模板假冒识别。
- 用户可校订并确认；生成端实际收到确认版本的文字及对应原图，而不是只在页面展示。
- 无任何划区贴片亦可走完整外观锁定流程。
- 用不同商品及换背景/生活场景样例核对形状、配色、材质、部件关系和标识；如有偏差如实报告。
- AI无法辨认的文字与遮挡部件显示未知；不宣称完全锁死或保证合格。
- AI理解、重绘、外观核验分别有真实或明确标识的离线验证证据。
